# typeglass-cli

`typeglass` is a Rust CLI for lazy navigation of type relationships in large codebases.

It is designed around strict type-level domain modeling:

- Business rules encoded in types
- Typestate for lifecycle boundaries
- Typed errors for every recoverable failure
- Exhaustive handling, no stringly-typed fallbacks

## Current status

This repository currently contains the initial type-first scaffold and domain model skeleton.
